# Timberlite (Fabric, Minecraft 1.21.1)

## Build it (needs Java 21 + Gradle)
    gradle build
The mod jar appears in build/libs/ (use the one WITHOUT "-sources").
No Gradle? Open this folder in IntelliJ IDEA and it sets everything up; run the "build" task.

## Install
1. Install Fabric Loader for 1.21.1 and put Fabric API in your mods folder.
2. Drop timberlite-1.0.0.jar into the same mods folder.

## Use
1. Hold an axe.
2. Chop a log. The whole tree falls. Sneak to chop just one log.
Each log costs 1 durability; up to 128 logs per chop.
